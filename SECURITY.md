# Security Policy

If you find a security vulnerability in Sonosphere, please do not open a public issue or pull request.

Instead, report it privately through one of these channels:

- **GitHub:** Use the "Report a vulnerability" button in this repository's Security tab.
- **Email:** Send details to [support@sonosphere.fm](mailto:support@sonosphere.fm).

Please include steps to reproduce the issue, the affected endpoint or page, and the potential impact if you know it. We'll respond as soon as we can and coordinate a fix before any public disclosure.

Because Sonosphere is a free, open source, not-for-profit project, we unfortunately can't offer monetary bounties at this time. We will gladly credit you for the disclosure (unless you'd prefer to stay anonymous).
